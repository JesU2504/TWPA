# HFSS model inputs

- `amplifier_config.json`: operating point, supercell counts, and base grid.
- `hfss_cell_parameters.csv` and `.fit.json`: loaded/unloaded structural fits,
  regenerated by `scripts/fit_hfss_unit_cells.py`.
- `kinetic_*_debug.s2p` and `kinetic_*_lowfreq.s2p`: broadband and low-frequency
  two-port data at nine retained stub lengths.
- `supercell_15_4_15_{low_1_3GHz,fine_3_14GHz,aux_14_27GHz}.s2p`: baseline
  34-cell supercell exports, with 12.1 µm long stubs and 50 Ω reference ports.
- `supercell_15_4_15_zmatched_*.s2p`: corresponding stub-only redesign exports.

Local filesystem paths have been removed from the Touchstone `! File:` headers.
All other export contents, including numerical data and simulation metadata, are unchanged.

The original six exports for 40, 50, and 60 µm are unavailable. Restore
`kinetic_40um_debug.s2p`, `kinetic_40um_lowfreq.s2p`, and similarly named pairs
for 50/60 µm here to enable refitting. Until then, the runner explicitly uses
the archived fits in `data/reference/`.

See `docs/FIGURE_WORKFLOW.md` for limitations, including the 12.0 µm structural
fit versus 12.1 µm supercell geometry, zero-loss policy, and out-of-band fallback.
